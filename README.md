# DecisionIQ
DecisionIQ is an AI-powered platform that predicts demand, detects inventory risks, and recommends optimal purchasing decisions using machine learning, MILP optimization, and RAG.

Areas we need to build and improve:

📊 Sales and demand forecasting — ARIMA, Random Forest, XGBoost

⚠️ Risk assessment and anomaly detection

🧠 Decision engine and Multi-Criteria Decision Making (MCDM)

🔄 What-if analysis and scenario simulation

📚 RAG pipeline for business documents and structured data

🤖 LangGraph-based workflow orchestration and LLM explanations

📈 Model evaluation, backtesting, and explainability

🖥️ Frontend, backend APIs, data pipelines, and database integration
